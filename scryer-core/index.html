Pipeline

LOAD → VALIDATE → DEDUPE → SCORE → ENRICH (passive DNS) → RANK → CSV + BRIEFS + SNAPSHOT

Deterministic core: same input → same output, sha256 manifest over the snapshot. One Rust binary, no cloud, no telemetry — data never leaves the operator's machine.
