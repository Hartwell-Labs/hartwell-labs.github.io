# Hartwell Labs — root site

This repository hosts the official **[Hartwell Labs](https://github.com/Hartwell-Labs)** website via GitHub Pages.

- `index.html` — the landing page (currently a styled "under construction" page; pure HTML + embedded CSS, no JS, no dependencies)
- [`.github/profile/README.md`](.github/profile/README.md) — shown on the organization profile page

## Local preview

Open `index.html` in a browser, or serve it:

```bash
python3 -m http.server 8080
# → http://localhost:8080
```

## Pages

The site is served at **https://hartwell-labs.github.io** (GitHub Pages from the `main` branch / root).
