Under the hood

A demo you can diff, not just watch.

Nothing here is a screenshot or a recorded clip. The page paints the interface pixel by pixel into a shadow buffer and blits it to the canvas, exactly the way the appliance paints into /dev/fb0.

Real

The interface

  • Renderer, palette and layout arithmetic ported from src/fbui.c
  • Glyph coverage bitmaps generated from src/font.h
  • Navigation, clock, licence states and the unlicensed boot path
  • Responsive tabs and the typed licence field
Simulated

The machine around it

  • Memory and uptime come from the page, not from a kernel
  • Licence verification accepts any well-formed HWO-XXXX-XXXX key
  • No fleet agent, no media ingestion, no state partition
  • Boot lines are the page speaking, not a bootloader
Shipped

What runs on hardware

  • A 27 MB ISO: Alpine base, kernel, DRM/evdev stack, one static binary
  • Ed25519 licence keys checked offline against the DMI UUID
  • No shell, no listening sockets, five UI exits then reboot
  • Media plays from PNG sequences on the state partition
