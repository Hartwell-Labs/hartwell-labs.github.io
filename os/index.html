Hartwell OS 1.0 · x86_64

One screen.
Nothing behind it.

An appliance OS for a production cell: no shell, no login, no listening socket. What you see below is not a video — it is the same renderer the image runs, ported to a canvas, down to the glyph bitmaps — rasterised at 2× so it stays sharp. Four screens, keys 1–4.

Real

  • Primitives, palette and layout arithmetic ported from src/fbui.c
  • Glyph coverage bitmaps generated from src/font.h
  • Navigation, clock, licence states, unlicensed boot path
  • Diffed against a QEMU framebuffer capture: zero differing pixels at 1×, drawn here at 2×

Simulated

  • Memory and uptime come from the page, not a kernel
  • Any well-formed HWO-XXXX-XXXX key is accepted
  • No fleet agent, no media ingestion, no state partition

On the box

  • 27 MB ISO, Alpine base, one static binary, BIOS + UEFI
  • Ed25519 licence bound to the DMI UUID, checked offline
  • Five UI exits → reboot. Media plays from a PNG sequence
  • Source is MIT; keys and signed images are the product
