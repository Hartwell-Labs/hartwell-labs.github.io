Hartwell OS

1.0 · x86_64

An appliance image that boots into one screen and offers nothing behind it: no shell, no login, no listening socket. 27 MB, BIOS and UEFI, licence checked offline against the board's UUID.

Image

Runtime
one static binary, PID 1 supervisor, no libc on target
Interface
1280×800, 32 bpp, drawn by the binary — no X, no Wayland
Licence
Ed25519, bound to the DMI UUID, verified offline; HWO-YYYY-XXXX
Exposure
no shell, no package manager, no remote login, no open port
Media
PNG frame sequence from the state partition, 1–60 fps
Fleet
optional outbound HTTP every 30 s; no inbound listener
Source

The screen above is the renderer from src/fbui.c compiled to JavaScript: the same primitives, the same layout arithmetic, the same glyph bitmaps — rasterised at 2× so it is sharp on the display you are reading this on. At 1× it matches a QEMU framebuffer capture pixel for pixel. Memory, uptime and licence checks in this session are simulated; on the box they come from the kernel and an Ed25519 signature.
