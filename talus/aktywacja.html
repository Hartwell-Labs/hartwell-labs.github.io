From key to running agent

  1. Download the binary

    One static ELF for x86_64 and aarch64, from the releases page. No kernel modules, no agent to install separately.

  2. Activate

    Run talus-monitor activate and paste the key from the email. The key binds to this machine and activates on this node.

  3. Watch

    talus-monitor run starts the eBPF probes. The dashboard and REST API come up on the port you chose during activation.
